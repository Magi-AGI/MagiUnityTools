MagiUnityTools (UPM)
====================

Common Unity patterns, diagnostics, and utilities used across Magi-AGI Unity projects.

Packages
- `com.magi.unitytools` — runtime helpers (patterns, diagnostics, math) and editor tooling.

Structure
- `Packages/com.magi.unitytools/package.json`
- `Packages/com.magi.unitytools/Runtime/{Patterns,Diagnostics,Math}`
- `Packages/com.magi.unitytools/Editor/{Analyzers}`
